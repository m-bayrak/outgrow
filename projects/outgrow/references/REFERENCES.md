# Reference materials

All files below were supplied for this project and are stored next to this file in [`images/`](./images/) and [`videos/`](./videos/). Use them to understand rhythm, camera language, contour transformations, and the story of the orange soul. Do not copy titles, logos, typography, or sequences frame-for-frame.
